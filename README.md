# AP-Digital-Protfolio
A collection of my work completed throughout the AP Computer Science Principles (AP CSP) course, documenting my development as a programmer through projects, problem-solving, experimentation and reflection.


This repository serves as a digital record of my AP CSP coursework and demonstrates how I applied programming concepts to create functional software while developing my understanding of the software development process.

About This Portfolio

This portfolio contains selected coursework and programming work completed during AP CSP.

Rather than focusing only on the final programs, this repository documents my learning process and the development of my programming skills. The projects demonstrate my ability to break problems into smaller components, design solutions, write and refine code and reflect on the decisions made during development.

The portfolio includes:
- Programming projects developed during AP CSP
- Source code and implementation materials
- Project documentation
- Screenshots and demonstrations
- Reflections on the development process
- Supporting AP CSP materials
